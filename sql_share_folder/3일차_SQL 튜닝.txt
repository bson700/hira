SQL 문장의 처리 과정 

1. PARSE  - 구문 분석 (실행 계획 확보)
  - 문법 검사 
  - 의미 분석 (객체, 권한 유/무 확인) 
  - IF 실행 계획 존재 유/무 (동일 문장 체크) 
      TRUE: 실행 계획 재사용 
     FALSE: 실행 계획 생성 및 저장 

2. BIND    - 바인드 (바인드 변수에 값 입력) 
3. EXECUTE - 실행 (실행 계획 사용)
4. FETCH   - 인출 (SELECT 명령문만)
