해쉬(Hash = Message Digest)
==========================
임의 크기 입력 -> 고정 길이의 유일한 값 출력

단방향 = 일방향 = One Way = 입력값으로 해쉬를 계산할 수 있지만, 역연산은 불가능 
==> 인증 정보 저장 및 처리

사용자 -> PW --------- A + K ---------> E(PW)
                      ~~~~~~~~~~~~~~~~~~~~~~ <== 관리자 또는 개발자가 알 수 있음
                                                 -> 패스워드 생성 주체가 아닌 제 3도 패스워드 원문을 알 수 있음

사용자 -> PW -------------------------> H(PW)
                                       ~~~~~
                                       패스워드 생성 주체만 패스워드 원문을 알고 있다는 것을 기술적으로 보장


유일성 = 입력값이 다르면 출력값(해쉬값)도 다름
==> 무결성 검사에 사용 

  data  --------------------------> data' -> H(data') ---+ 두 해쉬값을 비교해서 전달과정에 위변조 여부를 검증
                                                         |
H(data) --------------------------> H(data) -------------+


해쉬 크래킹(cracking)
--------------------
PW --> H(PW)  =  H(????)
                   ~~~~
                   원문 PW와 일치할 가능성이 있음
                   1) 사전 대입 공격
                   2) 무작위 대입 공격
                   3) 레인보우 테이블을 이용한 공격

--------------------
숫자 8자리의 패스워드인 경우 ==> 10^8

영문자+숫자+특수문자로 구성된 80자리 패스워드인 경우 ==> (26*2+10+13)^80
  ==> 사용의 불편함이 증가되고 사용 시 보안성이 떨이지는 문제가 발생
