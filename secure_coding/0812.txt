ID 중복 체크                          check.jsp?id=abc<script>alert('xss')</script>

                                                       |
                                                    "<%=rquest.getParameter("id")%>"는 존재...
                                                       |

반사 크로스 스크립트 취약점이 존재한다 것을 확인하면 공격자는 아래와 같은 공격 문자열을 생성해서
<a href="http://www.test.com/check.jsp?id=abc<script>alert('xss')</script>">궁금해 하는 내용</a>
불특정 다수에서 문자(SMS), 이메일, 단축 URL 형태로 전달

패스워드 변경 신청                       패스워드 변경 처리
changePwForm                            changePwProc

New PW 1: _______                       1) 인증 여부 확인
New PW 2: _______                       2) 처리에 필요한 값 중 
                                           사용자가 결정해야 하는 값이 전달되었는지 확인
          [ 변경 ]                      3) 처리에 필요한 값 중 
                                           서버가 가지고 있는 값을 확인 
                                        4) 사용자의 패스워드를 새 패스워드로 변경
